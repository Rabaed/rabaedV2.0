Optional fields are switched per board by each user from Card view layout. Contractor name is off by default; when on, it sits between Tags and Plan location as one muted line with the company icon. Toggle the switches to preview the card above. Header, subject, tags and owner can't be hidden.

File icon + submittal number on the start (right) side; revision badge — or approval code pill — pinned to the end (left).

The submittal title. Reads first. Max 2 lines, then ellipsis.

15px · Thmanyah Bold
