Filter panel · لوحة التصفية

Headerالترويسة

Basic / Advanced tabs. Saved filters opens a searchable menu grouped into Starred and My filters, with View all saved filters at the bottom. Save is enabled once any filter is set.

Field listالحقول

Every field you can filter on, grouped: workflow (Status, Trade, Document type, Owner, Role) · plan location (Zone, Building, Floor) · time (Created date, Days in column). A tomato count shows how many values are picked. Add field brings in Contractor, Revision, Approval code. Clear all at the bottom.

Valuesالقيم

Checkbox list for the selected field, with search when there are more than 5 values. Status/Role show their dot, Trade its chip, Owner the avatar, Days in column the dot scale. Dates are single-choice (radio).

Triggerزر التصفية

The toolbar Filter button shows the number of active fields and turns tomato while the panel is open.
