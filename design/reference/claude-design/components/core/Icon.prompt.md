Tabler-webfont icon mapped to the product's Vuesax/Iconsax-linear set. Paints with `currentColor`.

```jsx
<Icon name="search" size={20} />
<Icon name="document-download" size={18} color="var(--color-primary)" />
```

Pass a semantic `name` (search, bell, calendar, document, folder, trash, edit, settings, filter, building, user, chart, check, logout, more-vertical, …) or any raw Tabler id.
