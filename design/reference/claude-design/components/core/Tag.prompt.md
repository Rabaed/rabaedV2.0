Colour-coded discipline / submittal-type chip used on boards and tables.

```jsx
<Tag code="CV" />              {/* CV: Civil Works */}
<Tag code="SAR" showLabel={false} />  {/* just the code */}
```

Known codes: CV, AR, EL, SU, ME, MAR, SAR, DAS, NPD — each carries its own palette + default label. Override copy with `label`.
