# Sign-in page: the owner's design

`sign-in.html` is the owner's Claude Design export `Rabaed Sign in (standalone).html` (2026-10-27), with its embedded fonts removed by `pnpm design:strip-fonts`, so the page falls back to system fonts. Open it in a browser. RP-1057 builds the page to it.

The design shows features Rabaed doesn't have. The owner hasn't decided on them yet, so **the page leaves them out** (RP-1057):

- the Microsoft and Google sign-in buttons;
- "Forgot password?";
- "Keep me signed in";
- the Privacy, Terms and Help links, unless those pages exist.
