# Responsive web first; native offline app later

Site Reports, Snags and Inspections are filled in on site with patchy signal, which argues for an offline-capable native app. We launch with a responsive web app (including camera capture for photos) and build the native, modular app with offline capture next. The Form engine must still save Work Item drafts as self-contained, mergeable data from day one, so the offline app can be added without reworking Forms.
