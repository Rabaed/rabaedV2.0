# RP-593 scenarios

Rows of the [scenario matrix](../../visibility.md#scenario-matrix-becomes-the-automated-visibility-test-suite) added under RP-593, in its setup (Project "Tower", C1, C2, K1, OR, OW).

| # | Scenario | Who | Expected |
|---|---|---|---|
| RP-593-1 | On a Workflow ending with the Owner's review (1→1→1, ADR 0022), K1's PM recommends Code B to OW with a table of comments; OW's PM confirms it | C1 PM and engineer; OW; K1 | While OW reviews, C1 sees the item "With Owner review" (RP-598-1) and no Code anywhere: not in the List, search, the Kanban, the item, its history, the Activity Feed, notifications or the Dashboard, which read as before the Recommendation. OW and K1 read the Recommended Code B (its event, and the Recommendation's, written internal to each of them); OW is offered one Confirm, which issues B whichever of its closes is named. Confirmed, the item is closed at B for everyone, C1 reads the Code in its history, and the Comments are raised from K1's rows, by K1, held by C1 (seam 1: `apps/api/test/owner-review.test.ts`; seam 2: `packages/db/test/owner-review-rls.test.ts`) |
| RP-593-2 | OW Sends B Back to K1; K1's PM recommends C; OW confirms it | C1 PM and engineer; OW | The Send Back reaches K1 only; C1 still reads no Code. Confirmed, Code C is issued and C1 is offered a Revision; C1 never read B, anywhere, before or after; OW reads both Recommended Codes, B and C (seam 1 and 2 as RP-593-1) |
