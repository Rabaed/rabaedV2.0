# RP-1319 scenarios

Rows of the [scenario matrix](../../visibility.md#scenario-matrix-becomes-the-automated-visibility-test-suite) added under RP-1319: before its first Submit a Work Item has no Document Number (ADR 0030, RP-1316), and what RP-1316 left reads "No number yet" and the Subject, to those who see the item only: the Working Copy's and Documental Record's file names, Rabaed Admin's search for a stuck Step, and the Record verification (owner's decisions in RP-1319's description and comments 15938 and 15987). They sit beside V1, scenario 53 and the Verification page row. Their setup: Project "Tower", C1 the Contractor with an engineer and a PM, K1 the Consultant, an Owner Representative (OR; seam 2: the Owner with oversight, OW), and C2 a second Contractor, all covering every Trade and Location; a Rabaed Engineer on Rabaed Admin's connection. Seam 1 `apps/api/test/rp-1319-visibility.test.ts` (the Rabaed Default MAR; Rabaed Admin's own routes in `apps/admin/test/steps.test.ts`); seam 2 `packages/db/test/rp-1319-visibility-rls.test.ts` (the test Send Back Workflow, as the app role and rabaed_admin).
