# RP-1217 scenarios

Rows of the [scenario matrix](../../visibility.md#scenario-matrix-becomes-the-automated-visibility-test-suite) added under RP-1217, in the demo's sample Project "Al Nakheel District – Block A" (NKD): TMC Constructions (Contractor, Project Admin), Beta Build (a second Contractor), Design Consultants LLC (Consultant) and Al Waha PMC (Owner Representative), with 103 Submittals and a full Snag List, seeded through the api as the demo people (`apps/api/src/demo/sample-project.ts`).

| # | Scenario | Who | Expected |
|---|---|---|---|
| RP-1217-1 | TMC raises 103 Submittals; 12 stay in its Internal Review (8 new items with the PM or returned to the Engineer, 4 Revisions of Code C items), the rest are Submitted | Design Consultants' Engineer and Manager; Al Waha's engineer | The Consultant reads every Submitted one at its Stage (a revised Code C item as the Code C item, its Rev 1 not yet Submitted) and none of the 12, on the List, in its Stage counts and by id; Al Waha reads none of the 12 by id (V2, V3, V5; seam 1 `apps/api/test/sample-project.test.ts`, seam 2 `packages/db/test/sample-project-rls.test.ts`) |
| RP-1217-2 | The same Project, with Beta Build covering every Trade and Location TMC does | Beta Build's engineer | Reads none of TMC's Submittals or Snags: both Lists are empty (V3; seam 1 `apps/api/test/sample-project.test.ts`, seam 2 `packages/db/test/sample-project-rls.test.ts`) |
| RP-1217-3 | Design Consultants' Engineer sends a Submittal to the Manager with a Recommended Code and an Internal Note | TMC's engineer and PM; Al Waha's engineer | Their history of the item has no `recommend_code` or `internal_note` event, or the item is hidden from them; Design Consultants' Manager reads both (V5; seam 1 `apps/api/test/sample-project.test.ts`, seam 2 `packages/db/test/sample-project-rls.test.ts`) |
| RP-1217-4 | Design Consultants' Engineer who covers Mechanical Works only, on a Project of three Trades | That engineer | Reads only the Mechanical Submittals, and the Stage counts of those alone (V3; seam 1 `apps/api/test/sample-project.test.ts`, seam 2 `packages/db/test/sample-project-rls.test.ts`) |
| RP-1217-5 | Beta Build's Authorized Person is on Jeddah Corniche Villas only; Beta Build is a Participant of NKD | Beta Build's Authorized Person | NKD is not in their Projects, and its page and List answer the plain 404 (V1, V2; seam 1 `apps/api/test/sample-project.test.ts`, seam 2 `packages/db/test/sample-project-rls.test.ts`) |
