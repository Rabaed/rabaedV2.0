# RP-1299 scenarios

Rows of the [scenario matrix](../../visibility.md#scenario-matrix-becomes-the-automated-visibility-test-suite) added under RP-1299 (UAT round 0, WF-01; the owner's decision of 2026-11-13: a Member who is not a Project Admin sees only the Workflows in use, and the Project Admin keeps the full list). The setup is Project "Tower": C1 the Host Company, whose Project Admin created it; C1's engineer and PM; K1's manager; C2, a second Contractor, and its engineer; and a Member of another Project. The Tower's MAR runs one of the eight Rabaed Default submittal Workflows (RP-596). "In use" means the Workflow a Type runs, or the Workflow of an exception the reader reads (V15). Seam 1: `apps/api/test/rp-1299-visibility.test.ts`. Seam 2: `packages/db/test/rp-1299-visibility-rls.test.ts`. The filter itself is in the api read; seam 2 checks the row-level security it is built on: who is a Project Admin, which bindings each reader reads, and that the rows of a Workflow not in use stay open (V20), so only the api's lists leave it out.
