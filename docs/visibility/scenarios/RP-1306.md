# RP-1306 scenarios

Rows of the [scenario matrix](../../visibility.md#scenario-matrix-becomes-the-automated-visibility-test-suite) added under RP-1306, in its setup (Project "Tower", C1, C2, K1, OR, OW). The owner's decisions of 2026-11-16 (RP-1306 comment 15896) amend V10 narrowly: an approved supplier's SAR (its id, Document Number and Subject) goes only to a Member who already sees that SAR, checked at read time; everyone else reads the name alone, as for an entry added by hand.
