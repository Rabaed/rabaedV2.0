Rows of the [scenario matrix](../../visibility.md#scenario-matrix-becomes-the-automated-visibility-test-suite) added under RP-566, in its setup (Project "Tower", C1, C2, K1, OR, OW).

| # | Scenario | Who | Expected |
|---|---|---|---|
| RP-566-1 | A Rabaed Engineer adds an outcome to a Rabaed Default Type's set (MAR's shape; the test's own Type, since MAR's Versions are every suite's), then publishes a Rabaed Default Version whose Close sets it, from Rabaed Admin and from the `workflow:publish` CLI, while one Active Project created before (one Company's) lacks it; that Project's Project Admin then adds it; the same with a Stage.
